# LezTorrent

Торрент-клиент для Linux: свой бэкенд на WebTorrent и монохромный интерфейс в стиле liquid glass.

## Запуск

```bash
npm install
npm run app      # окно (Electron)
npm start        # только сервер → http://127.0.0.1:8642
```

## Что умеет

- magnet-ссылки и `.torrent`: вставка, перетаскивание, двойной клик в файловом менеджере
- очередь загрузок, лимиты скорости, остановка раздачи по рейтингу или времени
- выбор файлов внутри торрента, перепроверка целостности
- проверка свободного места до начала загрузки, своя папка для каждого торрента
- «пауза всё», сон или выключение, когда всё скачается
- трей, автозапуск, уведомления
